# 描画ソフトとしての照らし合わせ（AI を使わない機能）

AI を使わずに描く人が毎日使う機能を、ほかの描画ソフトの水準と AtelIer の今で並べた表です。
長期の開発の 1 周ごとに測り直し、下がった所と「無い」「壊れている」から順に直します。

見方:

- 比べる相手は CLIP STUDIO PAINT（CSP）、Krita、Photoshop（PS）、Procreate、MediBang、FireAlpaca、Paint Tool SAI です。調べた事実と出所は docs/knowledge/tech/2026-11-23-psd.md にあります。MediBang・FireAlpaca・SAI は公式の資料を見ていないので「一般に有る（未確認）」と書きます
- AtelIer の今は 4 つで分けます。有る（窓で道具の帯・欄・マウスから押して最後まで動いた）、動く（有るが、ほかのソフトの水準より弱い）、壊れている（押すと結果がおかしい）、無い
- 窓は Linux の offscreen で開き、試験と同じ経路（道具の帯を押し、絵の上をマウスで押して動かして離す）で流しました。ペンタブレットの実機、Windows、筆圧の実際の感触は見ていません
- 「直した」「作った」は、この周（2026-11-23）に手を入れた物です

## 残りの順番（次の周から上から進める）

1. 自由変形を絵の上の取っ手でつかんで変える形（今は数を入れる窓）と、ゆがみの 4 隅（遠近）
2. バケツの「参照レイヤーに設定」（決めたレイヤーだけを見る）。塗りつぶしと入り抜きの設定はブラシの欄に出した（2 周目）
3. 合成モードの残り（カラー・輝度・色相・彩度・除外・リニアライトなど）と、市松の背景に掛かる見え方の違いを直す
4. レイヤーフォルダーの入れ子
5. 筆圧の曲線を点で描いて決める設定と、ペンの向き（平筆の角度）
6. 取り消しの回数の設定
7. PSD の ZIP 圧縮・16 ビットの読み込み、レイヤーマスク
