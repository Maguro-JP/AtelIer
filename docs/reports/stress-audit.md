# ストレスになる所の一覧

初めて使う人として、空の置き場から窓を offscreen で動かし、主な作業ごとに押す回数・秒数・出た窓を数えました。
窓の写しは手元の作業用の置き場に撮り、目で見ました（リポジトリには入れていません）。重い順に並べています。

測った値（offscreen、空の置き場、1 回ずつ）

| 作業 | 秒 | 手数・窓 |
|---|---|---|
| 起動（読み込みから窓が出て最初の確かめが終わるまで） | 1.45〜1.87 | 窓が 3 枚続けて出る（はじめに、言葉の模型、モードを選ぶ） |
| 2 回目の起動（1 回目で窓を閉じるで閉じた場合） | 1.45 | 窓が 2 枚また出る（はじめに、モードを選ぶ） |
| 新規キャンバス | 0.03 | 1 手（Ctrl+N）。確かめの窓は無し |
| 描く（ペンで 1 本） | 0.01 | 起動したときの道具が手のひらなので、道具を選ぶ 1 手が要る |
| レイヤーを足す | 0.04 | 1 手 |
| 保存（初めて） | 0.29 | 2 手（Ctrl+S と置き場を選ぶ） |
| 開く | 0.10 | 2 手 |
| 設定を開く | 0.17 | 1 手 |
| 終わる（保存していない変更あり） | 0.02 | 確かめの窓 1 枚 |

## 直した物

| 重さ | 何 | 前 | 後 | 場所 |
|---|---|---|---|---|
| 戻せない | 新規キャンバスで、描いた絵が元に戻すで戻らなかった（説明には「元に戻すで戻せます」とあった） | 積み重ねが 1 から 0 になり、元に戻すで戻る手が 0 | 前の絵を 1 手として積み、元に戻す 1 回で前の絵に戻る | atelier/app/window/files.py の new_blank |
| 戻せない | 作業ファイルを開いたあとに新規キャンバスにして保存すると、前の作業ファイルを白い絵で上書きした | 保存で置き場を聞く窓が 0 枚（上書き） | 新しい絵として置き場を聞く窓が 1 枚出る | 同上 |
| 答えが無い | 保存が終わっても、帯に「保存しています…」が残り続けた | 次の知らせまで残る | 終わったら「保存しました」を 3 秒出して消える | atelier/app/window/files.py の save_project |

試験は tests/test_new_canvas_undo.py です（直す前の版では落ち、直した版で通ります）。

## 残した物（重い順）

| 重さ | 何 | 見た所 | 残した理由 |
|---|---|---|---|
| 高 | 初めての起動で確かめの窓が 3 枚続けて出る（はじめに、言葉の模型、モードを選ぶ）。描き始めるまでに 3 回答える | 起動 | 窓をまとめる設計の変更で、開発として大きい |
| 高 | 「はじめに」と「モードを選ぶ」を閉じるで閉じると、次の起動でまた出る。言葉の模型は閉じると「使わない」として覚え、二度と聞かない。閉じたときの扱いが窓ごとに逆 | 起動を 2 回 | 何を覚えるかは利用者の決めることなので、決めてから直す |
| 高 | 起動したときの道具が手のひらで、初めての人がキャンバスをなぞっても線が出ない（積み重ねが 0 のまま） | 描く | 既定の道具を変えるのは設計の変更。設定の「起動したときの道具」で変えられる |
| 中 | 窓が狭い（800 幅）と、キャンバスが 160 画素ほどに潰れ、欄に取られる | 写し | ウィンドウ化の作業のファイル（layouts.py、window_fit.py、main_window.py）に重なる |
| 中 | 狭い窓で、帯に「緊急停止」が 2 つ並ぶ | 写し | 帯の組み立ては main_window.py に重なる |
| 中 | ツアーの吹き出しがキャンバスや欄の下に隠れて半分しか見えないときがあった（モードの窓を閉じた直後） | 起動の写し | 窓の重なりの順はウィンドウ化の作業に重なる |
| 中 | ツアーが出ている間に「描く」を押しても、何も起きず、帯にも何も出ない | AI で描く | ツアーの覆いの作りの見直しが要る |
| 低 | 新規キャンバスの大きさが 1200×1600 に決まっていて、選べない | 新しい絵を作る | 機能の追加になる |
| 低 | 保存に失敗したとき、作業ファイルの道が失敗した置き場のまま残り、次の保存も同じ置き場に書こうとする | 保存の作り | 起こしていない。読んで見つけた |

## 確かめていないこと

- AI で描く・赤ペンで直すは、模型が無い置き場なので、描くところまで通していません（押したときの答えだけを見ました）
- 窓の大きさを覚えるかは、offscreen の画面が 800×800 で大きさが切られるため、判定できませんでした
- Windows の本物の窓、ペンタブ、高い解像度の画面では見ていません
- 秒数は 1 回ずつで、ばらつきは測っていません
