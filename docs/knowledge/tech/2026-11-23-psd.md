## 情報

- CLIP STUDIO PAINT の塗りつぶしは「参照レイヤー」と「連結ピクセルのみに適用」で範囲を決め、線の濃い所まで塗る設定で線と色の間の隙間を防ぐ。https://tips.clip-studio.com/en-us/articles/590 、https://www.clipstudio.net/oekaki/archives/165870 （2026-11-23 に見た。公式の講座。「隙間閉じ」「領域拡縮」の語の公式の説明は今回の検索では見つけられなかった）
- Krita のレイヤーには Alpha Lock（透明度を変えない）と Inherit Alpha（下の絵の描いてある所にだけ見せる。クリッピングに当たる）がある。https://docs.krita.org/en/reference_manual/dockers/layers.html 、https://docs.krita.org/Introduction_to_Layers_and_Masks （2026-11-23）
- Procreate のブラシは StreamLine（手ぶれ補正）と Pressure Taper / Touch Taper（入り抜き）を Brush Studio で持つ。https://help.procreate.com/procreate/handbook/brushes/brush-studio-settings （2026-11-23）
- PSD のレイヤーの記録は、合成モードの 4 文字の鍵（norm・mul ・scrn・over など）、クリッピングの 1 バイト（0 が土台、1 がクリッピング）、flags の bit0（透明部分の保護）と bit1（隠す）を持つ。Adobe の PSD の仕様 https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/ （2026-11-23。出所は 1 つだが、書き出した PSD を Pillow で読み、自分の読み込みで往復させて確かめた）
- MediBang・FireAlpaca・SAI の公式の資料は今回は見ていない。表ではそれらの欄を「一般に有る（未確認）」と書く

## 知識

- 塗りつぶしの塗り残しは、アンチエイリアスの線のふちの半透明の画素が「近い色ではない」と判定されるのが原因。範囲を 1〜2 画素広げて線の下に潜らせると消える。線を別のレイヤーに置いている（塗りを線の下に置く）ときに使える。線と同じレイヤーに塗るときは、広げた分が線の色を塗りつぶすので 0 にする
- 隙間閉じは、線（近くない画素）を隙間の半分だけ太らせてふさぎ、その中で続きを探し、見つけた範囲を同じだけ太らせて戻す。戻すときは元の近い色の中だけにするので、線の外へは漏れない。隙間より細い所を押したときは、ふさいだ線で押した所が埋まるので、ふさがずに塗る
- 抜きは線の終わりが分からないと掛けられない。描いている途中は入りだけを見せ、手を離したときに記録した区切りから線を描き直して抜きを掛ける（SAI の入り抜きと同じ振る舞い）。押しただけの点や短い線は、入り抜きの長さを線の 1/3 までに縮め、点が消えないようにする
- 筆圧は区切りの両端の値を点ごとに移す。区切りに 1 つの筆圧だと、速く引いたときに太さが段になる
- クリッピングは「土台（下へたどって最初のクリッピングしていないレイヤー）の不透明度で切ってから、合成モードで重ねる」。土台が隠れていれば見せない（PSD と同じ）
- 透明部分の保護は、道具ごとに合成を変えるより、描いたあとに不透明度を描く前の値へ戻す方が漏れない（消しゴム・ぼかし・指先・文字・塗りつぶしの全部に 1 か所で効く）。消しゴムは不透明度しか変えないので、保護中は何も起きない（Krita と同じ）
- 限界: Qt の合成モードは市松の背景にも掛かるので、一番下が透明のときの見え方は作画ソフトと少し違う。PSD の読み込みは 8 ビット RGB・非圧縮と RLE だけで、ZIP 圧縮・16 ビット・CMYK は理由を出して断る。フォルダーは中のレイヤーを平らに並べて読む

## アルゴリズム

塗りつぶし（入力: 押した点、色の誤差 t、隙間 g、広げる画素 e、参照 all/layer。出力: 塗る画素の真偽の表）

1. 参照が layer なら今のレイヤー、all なら見えている絵を重ねた 1 枚を RGBA で読む
2. near = 押した点の色との差の最大が t 以下の画素
3. g > 0 なら r = ceil(g/2)。wall = 近くない画素を (2r+1) 四方で太らせた物。walk = near かつ wall でない。押した点が walk に無ければ walk = near
4. walk の中で押した点から行ごとに広げて続きを探す（スキャンライン）
5. g > 0 なら、見つけた範囲を (2r+1) 四方で太らせ、near の中だけに戻す
6. e > 0 なら 3×3 で e 回太らせる。e < 0 なら縮める
7. 選択範囲があれば、その中だけにする
8. 色を塗り、透明部分の保護なら不透明度を戻す

端の場合: 絵の外を押したら何もしない。費用は 1600×1200 で numpy と scipy の太らせが数十ミリ秒（測っていない。私の推測）。

入り抜き: 区切りごとに（a, b, a の筆圧, b の筆圧, 始めからの長さ）を覚える。点の掛け目 f(d) = min(1, d/入り, (全長−d)/抜き)。途中は入りだけ、離したら全部を描き直す。

```
halo gaps r58: 124 → 0            （アンチエイリアスの円の内側 360 点中、塗り残った点）
gap4 leak outside: 255 → 0        （4 画素の切れ目のある四角の内側を塗ったときの外の不透明度。隙間閉じ 4）
taper thickness start/mid/end: 2 12 2   （太さ 12 のペン。前は入り抜きが無く端まで 12）
clip outside (10,10): #ffffff  inside mul (100,60): #324b64   （クリッピング + 乗算）
alpha lock outside (20,120) a: 0  inside (100,120): #ff0000
psd: [('背景','normal',F,F), ('レイヤー 1','normal',F,F), ('レイヤー 2','normal',F,True), ('レイヤー 3','multiply',True,F)]
PIL reads psd: (200, 200) RGB 4
```
