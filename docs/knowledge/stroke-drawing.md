# ストロークで描き重ねる精度優先（設計）

## 目的

人の描き方と同じく、1 回で描かず、筆の運び（ストローク）で何度も重ねて描き進め、検品を通るまで描き続ける。
今の精度優先は、どの工程も模型が絵全体を 1 回で描き、`brush_reveal` はその差を筆で描くように見せているだけで、
レイヤーの画素はストロークで作られていない。

## 段

1. 消す: 直す所の線を、消しゴムでなぞって消す（`phase_tools.stroke_erase`。アプリの `paint.brush.stamp` の erase を使う）。
   面で塗りつぶさない。入れた所: ゴミ・欠片の消し、手・足・顔の囲みの描き直しの前。
2. 動かす: アタリのずれは描き直さず、切り貼り・角度・ずらしで直す（`reattach`、`lean_fix`、`recenter`）。
3. 塗りをストロークで重ねる: 模型の描いた色の絵を「目標」にし、大きい面から小さい面へ、
   `brush.stamp` のストロークで目標の色を少しずつ置いて重ねる。1 回の重ねで置く量を絞り、
   重ねるたびに検品し、崩れた所は消しゴムで消してから置き直す。
4. 線をストロークで描く: 清書の線の芯（`_strokes`）を、Gペンのブラシでなぞって描く（入り抜きは筆圧で付ける）。
5. 回数に上限を置かず、検品を通るまで 3 と 4 を繰り返す。止めるのは利用者だけ。

## 比べ方

段を足すたびに、precise-fast で前と後を同じ頼み・同じ種で描き、1 回描きと並べて見る。
下がる物（線の主張が強くなる、色が薄くなる、崩れが増える）は入れない。

## 今の状態

1 と 2 を入れた。3 と 4 は、模型の絵より崩れないことを確かめる台がまだ無いので入れていない（私の判断）。
